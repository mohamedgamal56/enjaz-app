# تطبيق "إنجاز" (Enjaz) - مواصفات المرحلة صفر (Phase 0: Foundation)

أهلاً بك يا بطل! ده مشروع تطبيق **"إنجاز"** - تطبيقك الشخصي لإدارة المهام والأهداف الحياتية أوفلاين بالكامل.
المشروع مبني بدقة حسب وثيقة المواصفات الرسمية، وبدون أي حاجة لتثبيت بيئة Flutter على جهازك الشخصي.

---

## 🚀 إزاي تجرب التطبيق فوراً على موبايلك الـ Redmi 12؟

### الطريقة الأولى: تجربة فورية من متصفح الموبايل (Web App)
1. اتأكد إن موبايلك والكمبيوتر متصلين على نفس شبكة الواي فاي (Wi-Fi).
2. افتح متصفح كروم على موبايلك واكتب العنوان ده:
   ```text
   http://192.168.100.11:8080
   ```
   *(أو على الكمبيوتر مباشرة: `http://localhost:8080`)*
3. هيفتح معاك التطبيق فوراً بمظهره وتصميمه الكامل وتقدر تقلّب بين الشاشات وتجرب المظهر الداكن والفاتح والعربي والإنجليزي!

---

### الطريقة الثانية: الحصول على ملف الـ APK وتثبيته على موبايلك (GitHub Action)
تم إعداد ملف **GitHub Action** جاهز في المسار: `.github/workflows/build.yml`.
عشان يشتغل ويطلعلك ملف الـ APK تلقائياً:
1. أنشئ مستودع (Repository) جديد على حسابك في GitHub وسمّه مثلاً `enjaz`.
2. اربط المشروع وارفعه للأمر ده من التيرمينال:
   ```bash
   git remote add origin https://github.com/<اسم-حسابك>/enjaz.git
   git push -u origin main
   ```
3. ادخل على تبويب **Actions** في صفحة المشروع على GitHub.
4. هتلاقي العملية شغالة وبتبني التطبيق، وخلال دقائق هتلاقي ملف **`Enjaz-Android-APK`** جاهز للتحميل والتثبيت المباشر على ريدمي 12!

## 📋 قائمة فحص واختبار المرحلة 0 (Test Checklist)

عشان تعتمد المرحلة دي وتوافق على الانتقال للمرحلة 1:

1. **التبديل بين التبويبات الأربعة**:
   - اضغط على (اليوم، الأهداف، الأفكار، الإحصائيات) واتأكد إن كل شاشة بتفتح.
2. **شريط التنقل المزدوج (Bilingual Labels)**:
   - اتأكد إنه في الوضع العربي بيظهر الاسم بالعربي وتحته الكلمة بالإنجليزي (مثل: اليوم / Today).
3. **زر الإضافة العائم (+)**:
   - موجود في شاشات (اليوم، الأهداف، الأفكار)، وغير موجود في شاشة (الإحصائيات) حسب المواصفات.
4. **تغيير المظهر (Light / Dark)**:
   - اضغط على أيقونة الإعدادات ⚙️ أعلى الشاشة، وبدّل بين "فاتح" و "داكن"، اتأكد إن الألوان بتتبدل فوراً.
5. **تغيير اللغة (عربي / إنجليزي)**:
   - من الإعدادات، اختار English، اتأكد إن واجهة التطبيق اتقلبت LTR، والعناوين أصبحت إنجليزية فقط، ولما ترجع عربي تتقلب RTL.
6. **تغيير صيغة الأرقام**:
   - جرّب التبديل بين الأرقام الإنجليزية (123) والمشرقية (١٢٣) وشوف التاريخ في شاشة اليوم بيتعكس مباشرة.

## 🛠️ تفاصيل المعمارية المنفذة في المرحلة 0
- **الألوان والتصميم**: ألوان التيل (#0D9488 / #2DD4BF)، حواف الكروت 16dp وبوردر 1px، وبدون ظلال نهائياً.

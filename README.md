# تطبيق "إنجاز" (Enjaz) — الإصدار الكامل النهائي (Phase 7: Final Release)

أهلاً بك يا بطل! ده مستودع تطبيق **"إنجاز"** - رفيقك الشخصي المتكامل لإدارة المهام، المشاوير، الأهداف الحياتية، والأفكار أوفلاين بالكامل 100% مع التسجيلات الصوتية وتقارير الإكسيل والنسخ الاحتياطي والأمان بالبصمة.
المشروع اكتمل بكافة مراحله السبعة وملحقاته الرسمية (v1.1 للـ Voice Notes و v1.2 للـ Excel Export) بدقة متناهية.

---

## 🚀 تحميل وتثبيت أحدث نسخة APK (الإصدار النهائي الكامل):

بمجرد رفع الكود على GitHub، يتم بناء ملف الـ APK النظيف تلقائياً عبر GitHub Actions.

### خطوات التحميل:
1. ادخل على صفحة المستودع على GitHub:
   👉 **`https://github.com/mohamedgamal56/enjaz-app`**
2. اضغط على تبويب **Actions** من القائمة العلوية.
3. اضغط على آخر تشغيل للـ Workflow (اسمه **Build Flutter APK**).
4. في أسفل الصفحة في قسم **Artifacts**، حمّل ملف:
   📦 **`enjaz-app-apk`**
5. فك الضغط وثبت `enjaz-app.apk` مباشرة على موبايلك الـ Redmi 12!

## 🌟 ملخص ما تم إنجازه عبر المراحل السبعة:

1. **المرحلة صفر (Phase 0: Foundation)**:
   - واجهة Material 3 باللغتين العربية والإنجليزية، خطوط Cairo و Inter، المظهر الفاتح والداكن، وقاعدة بيانات Drift أوفلاين.
2. **المرحلة الأولى (Phase 1: Tasks Core)**:
   - الإضافة السريعة، الحالات السبع للمهام، تسجيل أسباب التأجيل، السجل التاريخي المتصل، وشريط التراجع (Undo).
3. **المرحلة الثانية (Phase 2: Organization & History)**:
   - أقسام شاشة اليوم (المتأخرة، المؤجلة، المكتملة المطوية)، صندوق المهام بدون تاريخ، سجل البحث المتقدم، وإدارة أسباب التأجيل، واللصق متعدد الأسطر.
4. **المرحلة الثالثة (Phase 3: Goals & Milestones)**:
   - إدارة الأهداف الحياتية بأسلوبين (مراحل وزنية ونسب رقمية)، ربط المهام بالأهداف، سجل تحديثات الأهداف، ومؤشرات القرب من الموعد.
5. **المرحلة الرابعة (Phase 4: Ideas & Voice Notes v1.1)**:
   - شاشة الأفكار بالوسوم والفلترة والتحويل لمهام وأهداف، محرك تسجيل وتشغيل الصوت AAC-LC بمشغل متعدد السرعات (1x, 1.5x, 2x) مربوط بالمهام والأهداف والأفكار.
6. **المرحلة الخامسة (Phase 5: Stats Dashboard & Excel Export v1.2)**:
   - لوحة إحصائيات تفاعلية (رسوم بيانية، نسب الإنجاز، مؤشرات الحماسة Streak)، وتصدير تقرير الإكسيل الحقيقي (.xlsx) أوفلاين بـ 7 أوراق عمل وتنسيق RTL.
7. **المرحلة السادسة (Phase 6: Reminders & Recurring Tasks)**:
   - تنبيهات محلية وإشعارات تفاعلية بأزرار "تمت" و"فتح"، الموجز الصباحي والمراجعة المسائية، والمهام المتكررة (يومي، أسبوعي، شهري).
8. **المرحلة السابعة (Phase 7: Safety, Backup & Final Polish)**:
   - **النسخ الاحتياطي الكامل (.zip)** شامل data.json و voice/ و manifest مع فحص SHA-256، وخيار النسخة الخفيفة.
   - **استرجاع النسخة الاحتياطية مع حفظ نسخة أمان تلقائية** قبل الاستبدال ومعاينة عدد العناصر.
   - **تصدير ملفات CSV** (ملف tasks.csv متضمناً عمود voice_note_count، وملف events.csv) بترميز UTF-8 BOM.
   - **قفل التطبيق والأمان**: حماية بالبصمة الحيوية أو PIN، ووضع الخصوصية `FLAG_SECURE` لإخفاء الشاشة في قائمة التطبيقات الحديثة ومنع لقطات الشاشة.
   - **تفريغ سلة المحذوفات نهائياً** مع الحذف الفيزيائي الفعلي لملفات التسجيلات الصوتية لتحرير الذاكرة.
   - تأكيد الخصوصية التامة: **صفر إذن إنترنت** في نظام أندرويد.
